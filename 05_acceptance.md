Acceptance Criteria

Project được xem là hoàn thành khi đáp ứng tất cả các tiêu chí sau:

Structure

 Có index.html

 Có đầy đủ Header/Navbar

 Có Hero Section

 Có Features Section

 Có CTA Section

 Có Footer

 Navbar có anchor navigation

Hero

 Có tiêu đề nổi bật

 Có mô tả

 Có CTA

 Có hình ảnh bất động sản

 Hình ảnh nằm bên phải trên desktop

 Mobile chuyển thành layout 1 cột

Features

 Có đúng 3 feature chính

 Lối sống thượng lưu

 Tiện ích tối ưu

 Pháp lý nhanh gọn

 Mỗi feature có hình ảnh riêng

 Layout responsive

Visual

 Background chính #f2f2f2

 Text/brand color #2d2d86

 Thiết kế tối giản

 Không bị tràn màn hình trên mobile

 Có hover state cho button/card

 Typography dễ đọc

Technical

 HTML5

 CSS3

 Vanilla JavaScript

 Bootstrap qua CDN

 Không có backend

 Không có PHP

 Không có React/Vue/Angular

 Không có database

 Không có API key

 Không có secret

Accessibility

 Tất cả hình ảnh có alt

 Navigation có thể sử dụng bằng keyboard

 Button/link có nội dung rõ ràng

 Contrast đủ tốt

Final validation

Sau khi hoàn thành:

Kiểm tra index.html có thể mở trực tiếp trên trình duyệt.

Kiểm tra tất cả CSS được load.

Kiểm tra JavaScript không có lỗi console.

Kiểm tra Bootstrap CDN hoạt động.

Kiểm tra responsive tại desktop, tablet và mobile.

Kiểm tra tất cả anchor trong Navbar.

Kiểm tra hình ảnh không bị méo.

Kiểm tra CTA hoạt động.
